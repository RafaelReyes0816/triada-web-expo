# Disponibilidad en la tríada CIA

La **disponibilidad** es el pilar de la tríada CIA que asegura que las personas autorizadas puedan usar la información, los sistemas o los servicios **cuando los necesiten**, sin interrupciones innecesarias.

Imagina una tienda web: no basta con que las contraseñas estén protegidas (*confidencialidad*) ni con que los precios y datos estén correctos (*integridad*). También debe poder abrirse y funcionar cuando un cliente quiera comprar. Esa capacidad de estar "lista para usarse" es la disponibilidad.

> **Definición fácil:** Disponibilidad es que el sistema, la aplicación o los datos estén accesibles y funcionando para quienes tienen permiso de usarlos.

---

## Ejemplos cotidianos

- Un cajero automático que funciona cuando necesitas retirar dinero.
- Una página web de matrícula universitaria que abre durante el periodo de inscripción.
- Una app de mensajería que permite enviar mensajes sin caerse.
- Un sistema de hospital que permite consultar recetas o citas en el momento necesario.

## Qué puede afectarla

- Caída del servidor o fallo de internet.
- Corte de energía.
- Demasiados usuarios usando la página al mismo tiempo.
- Un ataque que satura el sistema e impide que otras personas entren.
- Falta de copias de seguridad o de un plan para recuperarse después de un problema.

## Cómo se protege

| Medida | Explicación sencilla |
|---|---|
| **Copias de seguridad** | Guardar una copia de la información por si algo se pierde. |
| **Equipos de respaldo** | Tener otro servidor o servicio listo si el principal falla. |
| **Mantenimiento** | Revisar y actualizar los sistemas antes de que fallen. |
| **Planes de recuperación** | Saber qué hacer si la página o el sistema se cae. |
| **Protección contra ataques** | Evitar que alguien sature el servicio y lo deje inaccesible. |

## Dinámica: preguntas rápidas

**Formato:** muestra la pregunta, da 10–15 segundos y luego revela la respuesta.

### Pregunta 1

Si una página web está caída y los estudiantes no pueden inscribirse, ¿qué principio de la tríada CIA se vio afectado?

- A) Confidencialidad
- B) Integridad
- C) Disponibilidad ✅
- D) Ninguno

**Respuesta: C.** La información existe, pero no se puede acceder a ella cuando se necesita.

### Pregunta 2

¿Cuál de estas acciones ayuda más a mantener la disponibilidad?

- A) Ocultar contraseñas
- B) Hacer copias de seguridad y tener un servidor de respaldo ✅
- C) Cambiar los datos sin permiso
- D) Compartir información pública con todos

**Respuesta: B.** Las copias de seguridad y los sistemas de respaldo permiten recuperar el acceso tras una falla.

### Pregunta 3

Un atacante envía tantas solicitudes a una web que esta se vuelve lenta o deja de responder. ¿Qué está atacando?

- A) La disponibilidad ✅
- B) La confidencialidad
- C) La integridad
- D) La estética del sitio

**Respuesta: A.** Está buscando impedir que los usuarios autorizados usen el servicio.

### Pregunta 4

¿Qué situación representa una pérdida de disponibilidad?

- A) Alguien lee mensajes privados de otra persona
- B) Un archivo cambia sin autorización
- C) El sistema de pagos no funciona durante varias horas ✅
- D) Un usuario olvida su contraseña

**Respuesta: C.** El servicio no está accesible cuando debería estarlo.

### Pregunta 5

¿Cuál es la mejor forma de completar la frase? "La disponibilidad busca que la información esté…"

- A) Secreta para todos
- B) Correcta y sin cambios
- C) Accesible cuando se necesite ✅
- D) Guardada solo en papel

**Respuesta: C.** Es el acceso oportuno y confiable a la información o al sistema.

## Frase de cierre

> "La disponibilidad no solo significa tener datos guardados; significa poder usarlos cuando realmente los necesitas."
