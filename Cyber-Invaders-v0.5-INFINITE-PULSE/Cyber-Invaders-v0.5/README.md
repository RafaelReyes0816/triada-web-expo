# Cyber Invaders v0.5 — Infinite Pulse

Proyecto educativo en React + TypeScript con música importada por el jugador, crossfade, colores reactivos al ritmo y modo infinito.

Consulta [README-CYBER-INVADERS.md](README-CYBER-INVADERS.md) para instalación, controles y funcionamiento.

```powershell
npx --yes pnpm@11.1.3 install
npx --yes pnpm@11.1.3 dev
```

Abre http://localhost:5173/. La API Node + Express es opcional.
